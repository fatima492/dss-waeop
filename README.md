# DSS-WAEOP: Wind-Aware Energy Optimization for Agricultural UAVs

> **Wind-aware energy optimization for agricultural UAV operations: A dynamic soft set approach to trajectory planning under atmospheric variability**
---

## Overview

This repository contains the complete source code for **DSS-WAEOP** (Dynamic Soft Set Wind-aware Energy Optimization Protocol), a framework that couples dynamic soft-set atmospheric modeling with multi-objective NSGA-II trajectory optimization for agricultural spray UAVs.

Key results over 1,200 simulated scenarios and 30 Hardware-in-Loop missions:

| Metric | DSS-WAEOP | vs. BST baseline |
|---|---|---|
| Energy consumption | 487.3 Wh/ha [481.0, 493.7] | **−23.7%** |
| Field coverage | 94.7% [93.8, 95.5] | **+31.2 pp** |
| Spray precision | 87.8% [86.6, 89.0] | **+28.4 pp** |
| Spray drift | 26.1 cm | **−19.4%** |

## Installation

### Requirements

- Python ≥ 3.10
- ~500 MB disk (for full simulation data)
- RAM: 4 GB minimum (8 GB recommended for full 1,200-scenario run)

### Setup

```bash
# 1. Clone the repository
git clone https://github.com/fatima492/dss-waeop.git
cd DSS_WAEOP

# 2. Create a virtual environment (recommended)
python -m venv .venv
source .venv/bin/activate        # Linux / macOS
# .venv\Scripts\activate         # Windows

# 3. Install dependencies
pip install -r requirements.txt
```

### Option D: Correlated-OU sensitivity analysis (Section 6.13, ~1–3 h)

```bash
python reproduce_all.py corr-ou
```

Re-runs a matched 40-scenario subset under both the independent-OU and the multivariate
(correlated) OU wind models and reports how much the headline energy-reduction figure shifts
when the full ERA5 inter-parameter correlation structure (Appendix B) is injected via a
Cholesky cross-diffusion factor. Output: `results/tables/table14_correlated_ou_sensitivity.csv`.

## Baseline Implementations

All comparison baselines are **genuine predict-then-plan controllers**, not fixed fractional
adjustments of a reference method:

| Baseline | Implementation | Function |
|---|---|---|
| BST | Boustrophedon lawnmower | `bst_trajectory` |
| WA-BST | Wind-aware row reordering | `wa_bst_trajectory` |
| PID-T | Reactive-correction overhead model | `pid_trajectory` |
| MPC-PP | Receding-horizon low-potential planner | `mpc_trajectory` |
| GP-WP | Gaussian-process wind reconstruction + replanning | `gp_wp_trajectory` |
| CNN-MPC | Convolutional nowcast + greedy receding horizon | `cnn_mpc_trajectory` |
| PPO-RL | Energy-shaped stochastic policy | `ppo_rl_trajectory` |
| T-FSS | Fixed-parameter temporal fuzzy soft set + NSGA-II | via `NSGAIIOptimizer` |

## Scenario Design (1,200 Instances)

| Factor | Levels |
|---|---|
| Field size | 5, 10, 20, 40 ha |
| Terrain | flat, rolling, hilly |
| Seasonal wind regime | pre-monsoon, monsoon, post-monsoon, winter |
| Crop type | rice, wheat, orchards, vineyards |
| **Unique configurations** | **192** |

Each configuration is paired with ~6.25 independent OU wind-field realisations
(8 seeds for adversarial monsoon × hilly configurations, 6 for all others),
yielding **1,200 scenario instances**. Each instance is solved **30 times** with
distinct OU and NSGA-II random seeds. All confidence intervals use **B = 2,000**
bootstrap resamples over those 30 replications.

## ERA5 Wind Parameters

OU parameters (`θ`, `μ`, `σ`) were estimated by maximum likelihood from ERA5
hourly reanalysis data (2015–2024) for the Punjab agricultural region of Pakistan
(30°N–32°N, 73°E–75°E). Full parameter tables are in:
- `reproduce_all.py` → `OU_PARAMS` dictionary (§3)
- `results/tables/suppl_ou_parameters.csv` (after running the script)
